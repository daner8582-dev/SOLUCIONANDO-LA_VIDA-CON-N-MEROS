## PROBLEMA CON FIBONACCI

El crecimiento de árboles puede modelarse con Fibonacci cuando las ramas se dividen siguiendo un patrón repetitivo.
Idea básica
Imagina un árbol donde:
- en el primer año aparece 1 rama.
-algunas ramas producen nuevas ramas al siguiente año.
- las nuevas tardan un tiempo en volver a ramificarse.
## Ejemplo:
Año	Número de ramas
1	1
2	1
3	2
4	3
5	5
6	8
# Entonces :

El programa le pedira al usuario que ingrese los años del arbol y calculara las ramas que tendra en dicho año. 

## PROBLEMA USANDO NUMEROS PRIMOS
Descripción del problema cotidiano

En una escuela, un maestro desea organizar a sus estudiantes en grupos iguales para una actividad.
Para saber si esto es posible de varias maneras o solamente de una forma, necesita verificar si la cantidad de estudiantes es un número primo.

Un número primo es aquel que solo puede dividirse exactamente entre 1 y sí mismo.

El programa permitirá que el usuario ingrese la cantidad de estudiantes y mostrará si el número es primo o no.

Datos que pedirá al usuario

## El programa solicitará:
La cantidad de estudiantes o número a evaluar.
## Resultado esperado
El programa indicará:
“El número es primo”
o
“El número no es primo”.
